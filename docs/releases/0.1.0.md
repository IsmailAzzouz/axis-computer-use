# AXIS 0.1.0 — V2 alpha

AXIS now has one implementation: V2. This is a breaking release for users of the
earlier CLI, SDK, and MCP contracts.

- Six compact MCP tools: `axis.help`, `axis.targets`, `axis.observe`, `axis.run`,
  `axis.job`, and `axis.capture`.
- Bounded multi-action plans, idempotency keys, explicit effect verification,
  contextual targets, and supervised native workers.
- Windows accessibility, keyboard/mouse input, OCR, gestures, UI changes, and
  calibrated temporal recipes without requiring model video input.
- Bounded recovery from stale UI Automation roots, with no replay of input.
- V1 code, platform adapters, historical dispatchers and documentation removed.
  A portable platform interface remains available for future OS adapters.

Install the attached wheel with its Windows dependencies:

```powershell
python -m pip install './axis_computer_use-0.1.0-py3-none-any.whl[windows]'
axis --help
```

Start with `axis.help({})` once MCP is configured. See
[setup and API](../AXIS_V2_API.md) and [migration](../AXIS_V2_MIGRATION.md).

This alpha is not production-certified. Local automated tests and installed
package checks do not establish the 100-trial reliability target. Current-build
Excel/Edge qualification, model usability trials, resource endurance, and
macOS/Linux implementations remain open; see [qualification](../AXIS_V2_QUALIFICATION.md).
